# Security policy

Thanks for helping keep the rec.farm tools and the people who run them safe.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the affected repository's
**Security** tab and choose **Report a vulnerability**
(`https://github.com/rec-farm/<repository>/security/advisories/new`).

Please don't open a public issue, pull request or discussion for a security problem.

Include what you can: the affected repository and version or commit, how to reproduce it, and
the impact you expect. We'll acknowledge the report, keep you updated while we fix it, and credit
you in the advisory unless you'd rather stay anonymous.

## Supported versions

Fixes land on each repository's default branch and in the next release. Some repositories
describe their own security model in a `SECURITY.md` or `docs/SECURITY.md`; where they do, that
file takes precedence over this one.
